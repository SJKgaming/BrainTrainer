# BrainTrainer

Modern Android brain training app built with Kotlin and Jetpack Compose.

## Features

* Addition training
* XP and level system
* Combo streaks
* Animated UI
* Neon dark theme
* Countdown timer
* Home screen navigation
* Custom numpad keypad
* Smooth question animations
* Haptic feedback

## Tech Stack

* Kotlin
* Jetpack Compose
* Material 3
* Compose Animation

# BrainTrainer 🧠⚡

Modern Android brain training app built with Kotlin and Jetpack Compose.

A fast-paced math reflex game focused on speed, focus, and mental calculation with a clean neon UI and smooth animations.

---

## Features 🚀

* ➕ Addition training mode
* 🔥 Combo streak system
* 🏆 Persistent high score saving
* 📈 Progressive difficulty levels
* ⏱️ Countdown timer gameplay
* 🎨 Modern neon dark UI
* 📱 Responsive mobile-friendly layout
* 🔢 Custom numpad keypad
* ✨ Smooth question transitions & animations
* 📳 Vibration feedback for correct/wrong answers
* 💾 DataStore local save system
* 🧊 Glassmorphism-inspired cards
* 🏠 Home screen + navigation system

---

## Tech Stack 🛠️

* Kotlin
* Jetpack Compose
* Material 3
* Compose Animation
* Android DataStore
* Coroutines

---

## Screens 📸

* Home Screen
* Gameplay Screen
* High Score Screen

---

## Gameplay 🎮

* Solve math questions before the timer ends
* Get 5 correct answers in a row to level up
* Questions become harder as levels increase
* Wrong answers or timeout reset your combo
* Highest level and combo are automatically saved
